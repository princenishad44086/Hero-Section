# Laundry Service Website

## About the Project

This is a simple **Laundry Service website** that I created using HTML and CSS. The main purpose of this project is to practice web page designing and understand how HTML and CSS work together.

The website has a clean and simple design related to laundry services.

## Technologies Used

* HTML
* CSS
* Viewport units (`vh` and `vw`)

## Features

* Navigation bar with Home, Services, About Us and Contact Us
* Logo and Username section
* Main heading for the laundry service
* Short description about the service
* "Book Service Today!" button
* Laundry-related image
* Simple and clean user interface

## Files Used

```text
Laundry-Service/
│
├── index.html
├── style6.css
└── README.md
```

## How to Run

1. Open the project folder.
2. Make sure `index.html` and `style6.css` are in the same folder.
3. Open `index.html` in a browser.
4. The website will open and display the laundry service page.
